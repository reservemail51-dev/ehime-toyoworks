# 愛媛東予Works 自社サイト

新居浜市を中心とした東予エリア向けの、ホームページ制作サービスのサイトです。
公開のしかたは **`公開手順.md`** を見てください（GitHub → Cloudflare Pages）。

## フォルダの構成
- `public/` … サイト本体。Cloudflare Pages ではこのフォルダだけを公開します（ビルド出力ディレクトリ：`public`）。
- `docs/` … 制作指示書・自動返信の文面・質問シートのテキスト版（公開されません）
- `tools/` … シェア画像のひな形・スクリーンショットの道具（公開されません）

## 見てみる
`public/index.html` をブラウザで開けば、そのまま表示されます（Googleフォントはネットにつながっているときだけ反映）。

## 実績を追加するとき（Claude Code への頼み方の例）
> public/images/works/cafe-xxx に画像を入れたので、「カフェ〇〇」を自主制作サンプルとして実績に追加して。業種はカフェ、規模は1ページ、ポイントは「メニューを写真で大きく」「予約ボタンを上に」。トップにも出して。

## 画像を差し替えるとき
`public/images/` に同じファイル名で上書きするか、Claude Code に「public/images に〇〇.png を入れたので差し替えて（WebPに変換して）」と頼んでください。

## 実績のスクリーンショットをつくる（任意）
パソコンに Node.js を入れて、このフォルダで `npm i -D playwright` のあと、
`node tools/screenshot.mjs maruichi https://公開したURL/`（maruichi の部分は実績のid）で `public/images/works/<id>/` に画像ができます。
