## 2. 技術ルール

- 静的な HTML / CSS / JavaScript のみ。ビルドツール・フレームワークは使わない。
- CSSは `css/style.css`、JSは `js/main.js` の共通ファイル＋必要最小限。ヘッダー・フッターは全ページで同じ内容をコピーで持つ（変更時は全ページ一括で直す）。
- 公開先は Cloudflare Pages（GitHub連携）。
- スマホファースト（幅360pxで崩れないこと）。本文16px以上、行間1.9前後、ボタンは指で押しやすい大きさ（高さ48px以上）。
- 画像は `images/` 配下、WebP推奨、`loading="lazy"`、必ず `width`/`height` と日本語の `alt` を付ける。
- 未用意の画像は、ファイル名を決めたうえで「ダミー枠（背景色＋ファイル名を小さく表示）」にしておく（ファイル名は **12章** の一覧に合わせる）。
- `CLAUDE.md` を作成し、上記ルールと「実績の追加手順」を書いておく。

2. **こんなこと、ありませんか？**：手書き風チェックリスト（4〜5項目、店主の口ぐせのような言葉で）。
3. **できること**：ホームページ制作／LP（1枚もののページ）制作／リニューアル。アイコン付き3カラムカードは使わず、イラスト＋短い説明の横並びリスト or ジグザグ配置。

6. **料金のめやす**：3プランを「名前・ひとこと・〇〇円〜」だけで表示。細かい内訳は出さず「くわしくはサービス・料金へ」「ご予算に合わせてご提案します」。

## 4. デザイン方針：「AIっぽくない・親近感のある」デザイン

コンセプト：**「ご近所のホームページ屋さん」**。つくっている人の顔と手の跡が見える、紙とペンの温かさ。

### カラー（`:root` にデザイントークンとして定義）

- 背景：生成り `#FAF6EE`（白一色にしない）
- 文字：墨 `#33302B`（真っ黒にしない）
- メインアクセント：みかん色 `#E9823A`（ボタン・マーカー）※愛媛らしさ
- サブ：瀬戸内ブルー `#3E7C8C`（リンク・見出しの小飾り）
- 差し色：若草 `#8FAF6B`（ごく少量）

### フォント（Google Fonts）

- 見出し：Zen Maru Gothic（700）
- 本文：Zen Kaku Gothic New（400/500）
- 手書きアクセント：Klee One（600）… 吹き出し・一言メモ・注釈など **短い言葉だけ** に使う

### 取り入れる表現

- 紙のようなごく薄いノイズ質感（SVGフィルター or 小さなテクスチャ）
- 写真はマスキングテープで留めたように、少し傾けて（-2〜2度）配置。すべて同じ角度にしない
- 手描き風の下線・丸囲み・矢印（SVGパスで線を少し揺らす）を見出しや大事な言葉に“ところどころ”
- セクションの切り替えに、ゆるい波線（瀬戸内の海のイメージ）を1〜2か所だけ
- FAQや「こんなことありませんか？」は **吹き出しの会話形式**（店主さん ⇔ 私）
- 左右非対称のレイアウト、要素の大きさにメリハリ。余白は“ゆったり”だが間延びさせない
- アニメーションは控えめ（ふわっと出る程度、全要素にはかけない。`prefers-reduced-motion` に対応）

### 禁止事項（AIっぽさの原因になるもの）

- 紫〜青のグラデーション、ネオン、ガラス風（グラスモーフィズム）、光る球体、宇宙・回路・ロボット系のモチーフ
- 「アイコン＋見出し＋説明」の同じ形のカードを3つ・6つと並べるだけのレイアウト
- 絵文字をアイコン代わりに使うこと
- 全部中央揃え・完全左右対称のページ
- 角丸と影の強いカードの多用、全要素のフェードインアニメーション
- 英語の大見出し（“Our Service” など）を日本語見出しの上に毎回置く演出
- 実在しない「お客様の声」や数字（「満足度98%」等）を作ること

## 5. 文章のトーン

- 一人称は「わたし」。です・ます調だけど、話しかけるようにやわらかく。
- 専門用語は使わないか、使うなら一言で言い換える（例：「ドメイン（＝ホームページの住所）」「LP（1枚で完結するページ）」）。
- 抽象的な決まり文句は禁止：「次のステージへ」「最適なソリューション」「ワンストップで」「ブランディングを加速」など。
- 具体的な地名・場面を入れる（例：「新居浜の商店街のお店」「西条のカフェ」「営業時間をインスタで毎回聞かれる」）。
- 押し売りしない。「まずは話だけ」「相談だけでも大丈夫です」を随所に。

## 7. 相談〜公開の流れ（flow.html）

1. **お問い合わせ**：LINE・フォーム・Instagram DM・メール、どれでもOK。「まだ決めていない」「相場だけ知りたい」も歓迎。
2. **ヒアリング**：基本は文字のやりとり。希望があればオンライン（Zoom／Google Meet／LINE通話）で30分ほど。事前に簡単な質問シート（5分で答えられる）をお送りする。
3. **無料デモ・お見積り**：お店に合わせたトップページのデモを作って、スマホで見てもらう。気に入らなければここでお断りいただいてOK（費用はかからない）。
4. **ご契約**：お見積りに納得いただいたら契約。お支払いは【仮：着手時50%・公開時50%、銀行振込】。
5. **制作・確認**：確認用のURLをお送りし、スマホで見ながら修正のご要望をLINE等でもらう。
6. **公開**：ドメイン設定・表示チェックのうえ公開。
7. **公開後**：おまかせプラン or セルフプラン（データお渡し）を選べる。

連絡手段の注意書き（contact.html と flow.html に記載）：
- 基本はオンラインで完結。お電話は受け付けておらず【仮】、LINEやフォームなら営業中でも気軽に送れます、という伝え方にする。
- 返信は原則24時間以内、対応時間を明記。

## 8. ドメイン・管理・譲渡の方針（faq.html に掲載）

FAQのカテゴリ：「料金について」「つくる前に」「つくっている間」「公開したあと」「ドメイン・データについて」。
下記の内容を、店主さんにわかる言葉で1問ずつ答える形にしてください。

- **ドメインは誰のもの？**：お客様名義で取得するのが基本（取得の代行も可）。私が辞めても、お店の住所がなくなることはない。
- **サーバー代は？**：原則0円の仕組みで公開。
- **公開後の更新は？**：おまかせプランなら私が対応。セルフプランなら自分で／都度依頼。
- **途中で管理を自分（や別の業者）に移せる？**：いつでも可。データ一式・ドメインの管理権限・フォーム設定・かんたんな手順書をまとめて「お引っ越し」できる（【仮：無料 or 〇〇円】）。
- **サイトの権利は？**：公開したサイトはお客様が自由に使える。制作実績として掲載させてもらえるかは事前に確認し、断ってもOK。
- **写真や文章はどうするの？**：お店にある写真・スマホ写真でOK。文章はヒアリングしながら一緒につくる。
- **ほかにも**：パソコンが苦手でも大丈夫？／インスタだけじゃダメ？／予約システムとつなげる？／どれくらいで出来る？／修正は何回まで？／支払い方法は？／遠方でも頼める？

## 9. 制作実績（ポートフォリオ）の仕組み

あとから私が実績を増やしていけるように、**データ1か所を書き足すだけで一覧・詳細・トップのピックアップに反映される**仕組みにしてください。

- データ：`data/works.js` に配列で持つ（`fetch` ではなく `<script>` 読み込みで、ローカルで開いても動くように）
  ```js
  {
    id: "maruichi",              // スラッグ（URLと画像フォルダ名）
    title: "お食事処 まるいち",
    type: "sample",              // "client"=受注実績 / "sample"=自主制作（架空） / "design"=デザイン案・バナー等
    industry: "飲食店",
    area: "新居浜市",            // 架空の場合は「架空」
    plan: "ライト",
    year: 2026,
    pickup: true,                // トップに表示するか
    thumb: "images/works/maruichi/thumb.webp",
    images: ["images/works/maruichi/pc.webp", "images/works/maruichi/sp.webp"],
    url: "",                     // 公開URL（あれば）
    summary: "1ページで完結する定食屋さんのサイト",
    points: ["メニューを写真付きで見やすく", "営業時間と定休日をいちばん上に"]
  }
  ```
- `works.html`：カード一覧＋絞り込みボタン（すべて／制作実績／自主制作サンプル／デザイン）。
- `work.html?id=○○`：詳細（PC・スマホの画面画像、こだわったポイント、プラン、公開URL）。
- **自主制作（架空）には必ず「架空のお店のサンプルです」バッジを表示**。受注実績と混同させない。
- 実績が0件のカテゴリは表示しない。「お客様の声」欄は `voice` が入っている実績だけに表示（ない場合は出さない）。
- 画像は `images/works/<id>/` に置く。サムネ800px幅、詳細1600px幅程度のWebP。
- 可能なら、公開済みのURLやローカルHTMLから **Playwrightで PC／スマホのスクリーンショットを撮り、端末フレーム風に並べた画像を作るスクリプト**（`tools/screenshot.mjs`）も用意し、使い方を `README.md` に書く。
- `README.md` に「実績の追加手順（Claude Codeへの頼み方の例文つき）」を書く。
  - 例：「images/works/xxx に画像を入れたので、『〇〇』を自主制作サンプルとして実績に追加して。業種はカフェ、ポイントは〜」

最初は既存の自主制作サンプル（まるいち・ときのや等、リポジトリにあるもの）を `type: "sample"` で登録してください。
