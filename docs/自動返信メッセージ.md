# 質問シートを自動で送るための設定メモ

問い合わせがあったとき、質問シートを自動で届ける方法は3つあります。

## 1. お問い合わせフォームのあと（サイトに設定済み）
フォームを送信すると表示される `thanks.html` に「質問シートに答える」ボタンを置いてあります。
設定は不要です（フォームの送信先を `thanks.html` に戻す設定だけしておけばOK）。

## 2. フォームの自動返信メール（SSGform の場合）
SSGform は無料プランでも「自動返信メール」が使えます（月100件まで）。
管理画面のフォーム設定で「自動返信メール」をオンにして、下の文章を貼り付けてください。
※送信者のメールアドレスが入った項目（name="メールアドレス"）を返信先に指定します。
※LINEの表示名だけを書いた方にはメールが届かないので、LINE側の設定（3）と組み合わせます。

件名：
【愛媛東予Works】お問い合わせありがとうございます

本文：
----------------------------------------
この度はお問い合わせいただき、ありがとうございます。
愛媛東予Worksです。

ご相談の内容を受け取りました。
返信は原則24時間以内にさせて頂きます。
（返信時間帯：基本7時頃〜20時頃／平日・土日問わず）

お時間があれば、下の「かんたん質問シート」にもお答えください。
選ぶだけの質問がほとんどで、5分ほどで終わります。
先に答えていただくと、無料デモのご用意が早くなります。

▼かんたん質問シート
https://ehime-toyoworks.reservemail51.workers.dev/hearing.html

※このメールは自動で送信しています。
※お心当たりのない場合は、お手数ですがこのメールを削除してください。

愛媛東予Works
メール：ehime.toyoworks@gmail.com
LINE：【LINE URL】
----------------------------------------

## 3. LINE公式アカウントの「あいさつメッセージ」
友だち追加されたときに自動で送られるメッセージです。無料で使え、メッセージ通数にも数えられません。
LINE Official Account Manager →「あいさつメッセージ」に、下の文章を貼り付けてください。

----------------------------------------
{Nickname}さん、友だち追加ありがとうございます！
愛媛東予Worksです。

ホームページのご相談は、このトークにそのままメッセージを送ってください。
「まだ決めていない」「相場だけ知りたい」でも大丈夫です。

お時間があれば、先に「かんたん質問シート」にもお答えください（5分ほどです）。
https://ehime-toyoworks.reservemail51.workers.dev/hearing.html

返信は原則24時間以内にさせて頂きます。
返信時間帯：基本7時頃〜20時頃／平日・土日問わず
----------------------------------------

さらに「応答メッセージ」で「質問シート」というキーワードに上のURLを返す設定をしておくと、
お客さんが「質問シート」と送るだけでいつでもURLが届きます。
（応答メッセージを使う場合は、応答設定で「チャット」と「応答メッセージ」を両方使える状態にします）
